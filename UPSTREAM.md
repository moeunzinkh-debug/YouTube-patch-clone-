## Selection made for this repository

Included are the YouTube patch package, its common patch packages (`all`, `shared`, and `util`), the YouTube extension and required shared extension modules, the Android stubs/build configuration those modules use, and resources needed by that source. The `patches-list.json` manifest lists 105 entries targeting `com.google.android.youtube` plus 5 generic entries with no app-specific target (110 entries total): the v1.48.0 YouTube-only set, which adds 9 patches over v1.47.0 (`Ask flyout menu`, `Custom font`, `Feed card layout`, `Feed video actions`, `Feed view count`, `Force animations`, `Series tracking`, `Skip live Shorts`, `Video delay`), with `Force system font` replaced by `Custom font`. Locale resource folders specific to Music and Reddit were removed. `21.23.492` is declared stable (matching upstream v1.49.0-dev.7+) so Morphe Manager recommends the same YouTube version as upstream; the experimental targets remain `21.42.241`, `21.41.525` and `21.28.208`.

Not included are the separate YouTube Music and Reddit extension/patch packages, their tests, and the upstream all-app bundle. `shared-youtube` is an intentional build/runtime dependency of YouTube and contains reusable helper code; its presence does not add the separate YouTube Music patch set.

This repository is therefore a **modified, YouTube-only source selection**, not a mirror of the complete upstream repository. Local changes include the filtered manifest and resources, a YouTube-only resource checker, removal of the Reddit locale list and YouTube Music Jam validation task, and metadata identifying this unofficial subset. The Voice-over translation code also adds Khmer-only TTS routing to the user's FastAPI Space via OpenAPI endpoint discovery, plus independent voice-over speed and pitch settings. The YouTube patch and extension sources are now aligned with upstream v1.48.0 (morphe-patcher 2.0.0 / patches-library 2.0.0). Local customisations — the Khmer voice-over TTS package, the YouTube-only resource checker, Khmer strings, fork metadata and build settings — were preserved via three-way merges. Shared support code remains where required. Additions also include the independent `tools/version-advisor/` catalog/advisor (which reads upstream `patches-list.json` metadata at runtime, but does not vendor upstream patch code) and the generated `docs/youtube-versions.md`. Upstream code attribution and the required notice are preserved.
