# Experimental Gboard Khmerlish overlay

This builds a separate Morphe `.mpp` from the verified `jasonwu1994/Gboard-patches` v4.0.0 source plus the existing Direct Translate overlay. It adds two independent opt-in selectors: offline Khmerlish and the Gmn Gemini chat translation router. The Khmerlish selector adds an off-by-default switch under Gboard **Patches** settings. The vendored upstream tree and existing published bundles/releases are not modified.

## Offline data and attribution

The compressed, byte-for-byte dataset `data/eng_khm_data.txt.gz` decompresses to SHA-256 `20158d40982b4860c2072038f751610b22815983d7be445021e2bcbe04501550`. It comes from [`Chhunneng/khmer-text-transliteration`](https://github.com/Chhunneng/khmer-text-transliteration/tree/fe8028f10296ba6299bebec5cea42b471a56dc0f) commit `fe8028f10296ba6299bebec5cea42b471a56dc0f`, `khmer_text_transliteration/data/raw/eng_khm_data.txt`. Copyright (c) 2025 Chrea Chanchhunneng; MIT license reproduced at [`overlay/patches/src/main/resources/gboard-khmer/LICENSE.txt`](overlay/patches/src/main/resources/gboard-khmer/LICENSE.txt), included in the MPP and copied with the dictionary into the patched APK.

`build_dictionary.py` deterministically filters to lowercase single-token Latin spellings and Khmer-script values. It drops single-letter and ambiguous entries, then applies the explicit examples/common spellings in `data/overrides.tsv`; the reviewed `o` → `អូន` is the only one-letter exception. The output has **24,506 exact matches**, not a contextual language model. Typing is processed temporarily in memory and is not automatically learned, logged or transmitted. Users can explicitly save personal pairs as described below. Check with `python3 tools/gboard-khmer/build_dictionary.py --check`.

## Operation and safety

The automatic setting sees a word boundary after normal typing, and only edits text observed in the same input session. It rechecks editor focus, cursor and the exact suffix before a batched edit. Personal multiword phrases take precedence over individual words when the last word is completed with a delimiter; previously converted words may briefly appear before the full phrase matches. A bounded, in-memory tracker holds only saved-dictionary prefixes and hashes, and fails closed if the editor changes or the relevant suffix is no longer visible. Unknown/ambiguous entries stay unchanged, and ordinary words only join a space inserted by this feature.

The separate toolbar icon opens an offline Khmerlish panel without enabling the automatic setting. Its lower input drives live replacement of the panel's own output in the host app. A horizontally scrollable prediction row uses the bundled dictionary plus the personal overlay, ranking personal entries first; tapping a candidate replaces the current Roman token. Curated ambiguous spellings include `men → មែន, មេន` and `man → ម៉ាន, មែន`. Predictions remain offline and no typed text is retained. It overlays the measured Gboard `keyboard_holder`, rather than the full IME decor (which may cover the app but have untouchable regions); it refuses to open if the holder is absent or too small. The panel's simplified QWERTY/symbol keyboard is separate from normal Gboard. `?123` opens the common symbol page including `_ - + '`, and `2/2` opens another page covering the remaining printable ASCII punctuation; other Unicode symbols can be pasted. Closing the panel restores the normal view and accessibility state. The output writer verifies the current editor, collapsed cursor and exact prior output before replacing anything.

Both Khmerlish modes ignore passwords, email/URL/numeric/no-suggestions and no-personalized-learning fields. A failed insertion triggers best-effort restoration; arbitrary editor implementations can still misbehave. There is no network component in the Khmerlish implementation.

## Gmn Gemini chat translation router

The separate **Gemini Chat translation router (experimental)** selector adds a `Gmn` toolbar access point. When the user explicitly selects non-sensitive editor text and taps Gmn, it creates a bounded translation prompt targeting the device language, copies that prompt to the Android clipboard, and opens exactly `https://gemini.google.com/app`. The user must paste and send the prompt in Gemini, then copy the result back. Gemini web does not provide this patch with a public no-key callback, so automatic prompt submission and automatic insertion of Gemini's response are not claimed. If no text is selected, or the editor is a password/private field, it opens Gemini without copying editor text. The patch embeds no API key, does not call the Gemini API, and does not log selected text. Clipboard contents and anything the user submits are still visible to Android, the browser, Google, and Gemini under their normal behavior and policies.

## Personal dictionary and word guide

In **Gboard settings → Patches → Khmerlish → Personal Dictionary & Documents**, search the bundled and personal spellings by Khmerlish or Khmer. Each result has an edit icon. Editing a bundled entry saves a reversible personal override; deleting it restores the original. Changing a bundled Roman key creates a new personal pair while keeping the original bundled entry unchanged. The **Personal** tab also adds, renames and deletes explicit pairs. Keys can include printable symbols, digits, Unicode/emoji and spaces, e.g. `p'o`, `p_o`, `p-o`, `p+o` or `min dg del`. They are case-normalized and limited to 64 UTF-16 code units (some emoji use two); repeated ASCII spaces normalize to one. Controls, line breaks, tabs and other whitespace are rejected. A value contains Khmer text (at most 128 characters, no line breaks or tabs). Both conversion modes use the longest matching saved personal key, including multiword keys, ahead of bundled words. Automatic conversion completes on a delimiter (press space when the final symbol may be part of a key). Explicitly saved exact keys can override code/address safeguards; unsaved addresses and identifiers still retain the existing protections. This is a separate dictionary, not Gboard's personal dictionary.

Import UTF-8 `.txt`, `.tsv` or `.csv`: one pair per line as `khmerlish,ខ្មែរ` or `khmerlish<TAB>ខ្មែរ`, including multiword and symbol keys. An optional `khmerlish,khmer` header, `#` comments and quoted fields are accepted; quote keys containing a CSV comma or a double quote, or beginning with `#`, and double embedded quotes. Export quotes the necessary keys, preserving import/export round trips. PDF, DOCX, spreadsheets and malformed or duplicate rows are not supported. An import may contain at most 5,000 entries and 2.5 MB; the total personal dictionary is limited to 5,000. The entire file is validated off the UI thread before an atomic merge. Existing personal entries are preserved by default; replacing conflicts requires explicit confirmation, and stale previews fail without modifying the data. Export creates a UTF-8 TSV file for backup.

Only deliberately saved/imported pairs are stored in the app-private, credential-protected, **no-backup** directory. They are not synced or included in automatic Android backup; export before uninstalling, clearing Gboard data, or replacing a package. Import/export uses the Android file picker only when the user requests it. If private storage is locked or unavailable, Khmerlish conversion fails closed until the next input session can reload it; the ordinary keyboard remains available. The snapshot is refreshed at input start and after a local edit. No typed host-app text is automatically collected.

Gboard can autocorrect a Roman word before the automatic mode sees the space, in which case the feature safely skips it. Disable Gboard autocorrect for testing. This experiment targets only version name `18.5.4.993608717-release-arm64-v8a` and code `176049702`; new versions require a fresh review of the obfuscated lifecycle methods. Device and stock-Gboard behavior must be validated separately from algorithm tests and patching the already-patched third-party fixture.

To create the isolated source tree locally (requires the upstream Android/Gradle/Morphe packages toolchain):

```sh
python3 tools/gboard-khmer/test_khmer.py -v
python3 tools/gboard-khmer/apply_overlay.py /tmp/gboard-khmer-source
cd /tmp/gboard-khmer-source
./gradlew :patches:test --tests '*runtimeabi.*' :patches:buildAndroid generatePatchesList
./gradlew :extensions:extension:testDebugUnitTest --tests '*khmerlish.*' --tests '*geminirouter.*'
```
