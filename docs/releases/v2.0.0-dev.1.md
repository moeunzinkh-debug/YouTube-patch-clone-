## YouTube patches v2.0.0-dev.1 — pre-release

This is an unofficial **YouTube-only development bundle**, not a YouTube APK. The stable v1.49.0 release and its default source descriptor remain unchanged.

### What's new

- Upstream v2.0.0 YouTube source sync; **110 YouTube plus 5 generic patches**.
- Four new selectors: **Download post images**, **Search comments**, **Translate posts**, and **Niconico comments**.
- Recommended YouTube **21.30.216** on Android 10+ (SDK 29); Android 9 can use **21.23.492** (SDK 28). Experimental targets are hidden unless enabled.
- Keeps the custom in-app equalizer and player shortcut, Khmer FastAPI TTS, SEA-LION voice-over translation, previous additions, and Khmer strings. No separate YouTube Music or Reddit patch sets are included.

### How to use

Download `patch.mpp` below, then import it as a local patch source in Morphe Manager. The bundle requires Patcher 2.0.0 or newer. Morphe Manager 2.3.0-dev.3 was used for the application test.

Alternatively, add the [pinned development metadata](https://raw.githubusercontent.com/moeunzinkh-debug/YouTube-patch-clone-/refs/tags/v2.0.0-dev.1/docs/releases/v2.0.0-dev.1/patches-bundle.json) as a direct JSON source. It stays pinned to this version rather than tracking future releases. The repository's existing default source remains on stable v1.49.0.

### Verification and limitations

Morphe Manager on an Android 15 x86_64 emulator selected and applied 109 patches to a verified original YouTube 21.30.216 APK, including all four new selectors, EQ and voice-over. Morphe Desktop also completed patch application; 166 upstream YouTube JVM tests passed. The APK was not installed or launched. Device runtime, Android 9 behavior, player layout/audio, Khmer TTS playback, SEA-LION access, and live network features remain unverified.

**Privacy:** When you choose `Translate posts`, the selected post text is sent to the public Google Translate endpoint; if translation fails, the text may be offered to a translation app on the device. This is separate from the Instant Translate bundle, whose Google fallback was removed. Voice-over SEA-LION sends text to SEA-LION only when selected and requires your own API key.

Assets: `patch.mpp`, `patch.mpp.sha256`, and `patches-bundle.json`. See [full validation](https://github.com/moeunzinkh-debug/YouTube-patch-clone-/blob/arena/c4f8fd6a-youtube-patch-clone/docs/youtube-2130-validation.md).
