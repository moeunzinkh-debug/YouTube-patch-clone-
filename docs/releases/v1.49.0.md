## YouTube patches v1.49.0

### New
- **EQ player shortcut:** opens the existing in-app equalizer from the top control row near CC/settings. Uses native-relative layout and visibility, not an absolute overlay. Optional visibility switch under Video settings (restart required).
- **SEA-LION translation:** additional voice-over caption translation provider using `https://api.sea-lion.ai/v1/` and `aisingapore/Gemma-SEA-LION-v4-27B-IT`. Separate masked API-key field; existing providers preserved.
- Missing-key checks, streaming-error handling, and settings-export warnings covering translation API keys.

### Installation
Import `patch.mpp` in your patch manager and patch a supported original YouTube APK. Recommended stable target: **21.23.492**. Requires **Patcher 2.0.0**. Configure SEA-LION in Morphe settings → Video → Voice-over translation. Enter your key in-app, not in shared messages or files.

### Scope and verification
111 patches: 106 YouTube and 5 generic. No Music/Reddit additions. This is a fork version bump, not an additional upstream sync.

Android bundle compilation and offline checks run in CI. The existing EQ engine was reported working by the user; exact shortcut spacing across devices and live SEA-LION model access, translation quality and latency still need device/account verification. Caption text is sent to SEA-LION when selected. API keys may be included in settings exports—do not share them.

Assets: `patch.mpp`, `patch.mpp.sha256`, and `patches-bundle.json`.
